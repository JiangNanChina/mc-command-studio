## 验收入口

仓库内 `artifacts/mcstudio-local-preview-20261028-03/启动本地测试版.cmd`，Windows x64 免安装目录版。需保留同目录的 `win-unpacked`。

- 候选项和选中值中文优先，英文 ID 次级；属性、附魔、药水、刷怪笼、选择器、槽位、伤害、计分板、维度、旧版工具等共享一套中文组合框。
- 快捷命令、通用构建器、方块状态、游戏规则、声音、墙上旗帜及设置文案补齐中文显示。
- 保留深色风格、同行表单对齐、独立物品方案管理弹窗、五个模板分类及 51 个独立草稿。
- 修正 1.13–1.15 的旧属性名输入与生成，严格区分现代资源 ID。

## 验证

- 76 个测试文件、445 项 Vitest 用例通过；桌面端、核心和内容包 TypeScript 检查通过。
- 打包后表单可用性、中文优先组合框、旧版分组及方案、51 模板和旧属性边界检查通过。
- 截图、测试结果和校验摘要随本地目录提供。命令未在实际 Minecraft 游戏中逐项运行。

## 本地限制

本机普通 Electron 启动仍存在兼容问题，启动脚本使用 `--no-sandbox` 供本地验收，正式发布前需解决。此设置会关闭 Chromium 沙箱。

启动脚本使用当前测试目录中的独立 `user-data`，并关闭自动更新；旧测试版数据不会被覆盖。高级模板专有字段仍通过 JSON / SNBT / 组件文本编辑。

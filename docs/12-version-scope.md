# 版本范围：1.12–26.3

## 目标

正式支持：

> **Minecraft Java 正式版 1.12 到 26.3，共 54 个版本。**

1.8–1.11 已从正式范围移除，数据包与构建脚本已删除。


别名目录只保存 manifest，通过 `aliasOf` 读取基础包命令树/注册表/方块状态：

```json
{
  "id": "1.16.3",
  "gameVersion": "1.16.3",
  "dataVersion": 2580,
  "packFormat": 6,
  "aliasOf": "1.16.5"
}
```

版本号、`dataVersion`、`packFormat` 使用别名版本自己的元数据。

## 别名审计

`tools/pipeline/audit-aliases.mjs` 对比官方 summary 与基础包：

- 根命令集合
- 字面量数量
- 物品/方块数量

审计结果：

- 16 个有差异的补丁版已升级为独立包
- 9 个别名中 6 个完全一致
- 1.12/1.12.1/1.13/1.13.1 因官方 summary 缺失保留人工确认

详见 `docs/13-alias-audit.md`。

## 生成

```bash
pnpm data:build      # 生成 45 个基础包 + 重建 54 个版本目录
pnpm data:catalog    # 只重建版本目录
pnpm data:verify     # 校验基础包、目录、矩阵、覆盖率
```

## 限制

- 9 个别名复用基础包数据，不是逐字节补丁版数据。
- 1.12/1.12.1/1.13/1.13.1 无法用 mcmeta 自动审计。
- 1.12.2 使用 Legacy 原始构建器 + OOC。

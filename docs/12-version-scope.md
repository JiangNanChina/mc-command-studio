# 版本范围调整：1.12–26.3

## 目标

正式支持范围从“1.8 起的全部版本”调整为：

> **Minecraft Java 正式版 1.12 到 26.3，共 54 个版本。**

1.8–1.11 不再出现在版本选择器中，相关数据包与构建脚本已从仓库移除。

## 架构

### 基础包

命令树/注册表/方块状态变化较大的版本建立独立数据包，共 22 个：

```text
1.12.2 / 1.13.2 / 1.14.4 / 1.15.2 / 1.16.5 / 1.17.1
1.18.2 / 1.19.4 / 1.20.3 / 1.20.4 / 1.20.5
1.21.1 / 1.21.2 / 1.21.4 / 1.21.5 / 1.21.6 / 1.21.9 / 1.21.10 / 1.21.11
26.1 / 26.2 / 26.3
```

### 补丁版别名

同一个小版本内命令树与注册表基本一致的补丁版，通过 `manifest.aliasOf` 指向基础包：

```json
{
  "id": "1.20.6",
  "gameVersion": "1.20.6",
  "dataVersion": 3839,
  "packFormat": 41,
  "aliasOf": "1.20.5"
}
```

别名目录只保存 manifest，命令树/注册表/方块状态从基础包读取；版本号、dataVersion、packFormat 使用该补丁版自己的元数据。

共 32 个别名，例如：

- 1.12 / 1.12.1 → 1.12.2
- 1.13 / 1.13.1 → 1.13.2
- 1.14–1.14.3 → 1.14.4
- 1.16–1.16.4 → 1.16.5
- 1.20–1.20.2 → 1.20.4
- 1.20.6 → 1.20.5
- 1.21.9–1.21.11 使用独立包
- 26.1.1 / 26.1.2 → 26.1

## 生成

```bash
pnpm data:build      # 生成 22 个基础包，并重建 54 个版本的 index.json
pnpm data:catalog    # 只重建版本目录（需要已有基础包）
pnpm data:verify     # 校验基础包
```

元数据来自 `misode/mcmeta` 的 `versions/data.json`；生成器在本地没有缓存时会自动下载。

## 限制

- 别名不是逐字节的补丁版数据：命令树/注册表复用基础包。
- 对补丁版差异敏感的场景，优先使用对应基础包。
- 1.21.9–1.21.11 已补齐独立基础包。
- 1.12/1.12.1 的 dataVersion/packFormat 使用已知固定值，命令树复用 1.12.2。

- 基础包：22 个校验通过
- 别名加载：1.12、1.20.6 冒烟通过

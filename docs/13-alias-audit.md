1. `misode/mcmeta` 官方 summary

- 根命令集合
- 字面量数量
- 物品/方块数量

## 1.12/1.13 官方数据

### 1.12 / 1.12.1

1.12 没有数据生成器，使用官方服务端运行时 `help`：

- 1.12：64 个根命令
- 1.12.1：64 个根命令
- 两者完全一致
- 1.12.2 包已按该表补齐到 64 个根命令

补齐的管理命令：

```text
ban / ban-ip / banlist / deop / kick
pardon-ip / save-all / save-off / save-on
stop / tell / toggledownfall / tp / whitelist / locate
```

### 1.13.1

1.13/1.13.1 的 mcmeta summary 缺失，使用官方 server.jar 数据生成器：

```bash
java -cp server.jar net.minecraft.data.Main --reports generated/reports
```

结果：

- 1.13：66 根命令 / 408 字面量 → 升级独立包
- 1.13.1：67 / 410，与 1.13.2 完全一致 → 保留别名

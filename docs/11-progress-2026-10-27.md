## 2. 关键能力

### 多版本

- 26.3：完整可视化，94 根命令。
- 1.21.1：组件版，83 根命令；命令树、通用构建器、数据包格式可用。
- 1.20.4：NBT 版，82 根命令；NBT give/item/loot/gamerule + 44 个 NBT 安全表单，其余命令树。
- 顶栏可切换，选择记忆；非 26.3 显示版本提示。

### 数据包

- 数据包目录随版本切换：
  - 1.20.4：`functions` / `tags/functions` / `predicates` / `loot_tables` / `advancements`
  - 1.21+：`function` / `tags/function` / `predicate` / `loot_table` / `advancement`
- 谓词、进度、战利品表均有结构化编辑与 JSON 回退。

### 质量与发布

- Release 工作流新增 **打包版 Electron 冒烟门禁**，v0.1.33 起生效并通过。
- 自动更新链继续逐版本实测。
- 模板库把常用命令变成一键起点。
